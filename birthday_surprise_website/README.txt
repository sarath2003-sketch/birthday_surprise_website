BIRTHDAY SURPRISE WEBSITE
===========================

1. Open the "assets" folder.
2. Replace photo1.jpg ... photo5.jpg with the birthday person's photos.
   Keep the exact filenames, OR edit the photos array in index.html.
3. Open index.html in a browser to test.
4. For a public website, upload the whole folder (index.html + assets folder)
   to a static hosting service.

The site includes:
- 3D/glowing heart opening screen
- Arrow-to-heart explosion transition
- Animated birthday message
- Favourite-things selection section
- Gift box opening
- Automatic photo gallery with 3D flip/light effect
- Previous/Next controls
- Final birthday wish
- Starfield background and glowing UI

No server or database is required.
